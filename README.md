# Transparency

**Website: https://akshayan03.github.io/transparency-site/**

Tell Transparency what you're looking for — headphones, groceries, a gym, car insurance, a phone plan, anything — and your own Claude researches it live and gives you exactly three picks: the **lowest price**, the **best value** and the **best overall**. Each pick has the price (with currency and the time it was checked), a direct link to buy, three reasons, the main trade-off and a confidence level, plus the runners-up and every source. Prices that couldn't be verified are labelled as such.

This repository holds only the built website (static files served by GitHub Pages). The source code isn't public.

## How it works

- No server, no account, no analytics, no ads, no affiliate links.
- You connect your own Anthropic API key in Settings. It's stored only in your browser and sent only to `api.anthropic.com` (the site's Content Security Policy blocks every other connection).
- A search usually costs about $0.15–$0.45 on Claude Sonnet 5.5 (less on Haiku), billed to your own Anthropic account. A claude.ai Pro/Max subscription can't be used by websites.
- Don't have a key? Open any of the saved real example searches on the home page.

Prices change — always check the store before you buy. Not financial or insurance advice. See the site's Privacy and Terms pages.
